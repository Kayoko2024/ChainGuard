# 阶段9现场演示脚本

本脚本可匿名分享；所有动作只在本地测试环境。原始敏感数据不上链，网页状态不代替链证据。

1. **0:00–1:30 问题与范围**：恶意文档或邮件可能诱导模型越权。展示只读控制台，解释A账号/任务shadow、B任务强制/独立签名、C共同链历史。四节点同机，不声称四机构独立运维。
2. **1:30–4:00 合法发送**：选择C组normal/FINALIZED_OK，点实时核验。展示两个组织、同意图EIP-712签名、真实reserve和finalize hash/区块、工具签名/回执承诺。用命令导出HTTP核验JSON和四节点receipt，原MIME副作用由只读原卷验证器确认。
3. **4:00–6:00 越权与重放**：搜索document-injection或mail-injection，比较A实际副作用和B/C拒绝；C无预约不补造链拒绝交易。打开协议replay记录，展示相同actionId多次调用后邮箱没有新增。明确这是确定性协议演示，不是模型ASR。
4. **6:00–8:00 UNKNOWN与恢复**：搜索UNKNOWN，看到预约仍在、缺工具回执。页面不能据此声称没执行，也没有重发按钮。展示已独立验证的原回执恢复案例和reconcile交易。
5. **8:00–10:00 篡改/失联**：运行check_phase9_observer.py，修改证据副本被真实链核验拒绝；仅断开审计容器网络后显示UNAVAILABLE，恢复后再验。不能修改原记录或链来制造截图。
6. **10:00–12:00 可复现与限制**：展示一键部署/干净源码重建报告、实际测试命令、独立两轨统计与置信区间。解释旧历史权限状态查询失败、原入口null异常、官方完整utility不兼容、小样本与生产安全TODO。

可执行入口：`python scripts/demo_phase9.py`（默认只读）。`--fresh`重新通过原安全链路在新沙箱产生真实协议证据，并部署新的公开投影；不依赖现场模型API。LLM真实实验沿用阶段8单独命令与Key配置，绝不以固定trace替代。
