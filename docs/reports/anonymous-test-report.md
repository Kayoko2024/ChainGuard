# ChainGuard 匿名测试报告

版本：阶段9竞赛原型；日期：2026-10-26。报告不包含作者、机构、联系方式、设备名或本地用户路径。测试数据为本地合成数据；公开交易地址为测试公钥标识。

## 测试范围与证据标准

测试对象为独立只读审计控制台、公开证据投影、实时四节点/签名核验、一键部署、HTTP及真实浏览器冒烟、匿名材料和干净源码重建。原21份协议、8份共享策略与原安全业务模块不改；不以截图或页面状态代替链和工具证据。

阶段9开始实际基线为212项Python测试和71项Hardhat测试通过。审计observer初版17项自动测试通过；演示缺失读取适配的2项测试通过。最终数量、真实部署/浏览器/负向/重建结果在本报告末尾按实际运行补充；当前未结束的测试不提前标通过。

## 测试方法

1. 投影与接口：不暴露正文、盐、工具凭据和私钥；catalog摘要修改启动拒绝；无写业务路由；受限Host、CSP和no-store；链不可用时结论保留未知。
2. 真实链：四节点receipt及规范区块、实际交易input/events、EIP-712签名、组织角色、永久nonce、工具回执签名、AuditRegistry锚定。
3. 物理副作用：原验证器以无网络、只读挂载和SQLite mode=ro检查实际MIME与参数/结果/证据承诺。控制台公开投影不代替工具原卷。
4. 负向验证：修改意图、审批签名、工具回执、区块号、actionId的副本，要求真实查链返回INVALID；只断开独立审计容器网络，要求UNAVAILABLE，恢复后重新核验。
5. 浏览器：真实Edge/Playwright请求实际HTTP服务，不拦截网络，不替换响应；检查组织、签名、筛选、搜索、UNKNOWN和移动视口；页面无JS错误。
6. 新目录重建：新源码、venv、root/dashboard node_modules、锁定安装、pytest/Hardhat、React构建、无缓存Docker镜像、8081实际HTTP与浏览器。复用的系统和链依赖明确披露。

## 保留的失败与未完成项

- 旧阶段8证据的某个历史区块权限eth_call返回RPC -32603/Internal error，完整原验证器拒绝通过。回执存在不代表历史状态必定可查询；根因未凭猜测断言。
- 首两次一键部署中的原协议回放分别在normal和receipt-tamper的C案例遇到QBFT验证者null/TypeError；已产生副作用原卷保留，不冒称未发送。第三轮使用明确记录的演示传输适配；原核心入口间歇异常未修复。
- 首次干净重建的Python/Hardhat/React和无缓存镜像阶段完成，但所依赖的部署尚未通过、公开catalog不可用，HTTP验收失败；该运行保持FAIL，后续以新目录重建。
- 空白机器OS安装、新链完整部署、完整官方AgentDojo utility、生产多用户认证/机构独立托管、更大样本及第三方SMTP保证仍未验收。

## 结果与可信性边界

阶段8历史真实模型轨各组ASR0/3、TCR4/4；ASR Wilson95上界56.15%，不能解释为总体安全。模型无越权尝试时UER/UBR无分母。阶段9演示使用明确的确定性协议轨，不把它当新的真实模型攻击率。
